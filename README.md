# Chess.com User Stats ♟️

A Python command-line interface (CLI) tool that fetches and displays real-time stats for any Chess.com user using the official public API.  

## Features 🛠️
- Retrieve current ratings for **Rapid**, **Blitz** and **Bullet** time controls. 
- Clean and formatted terminal output.
- Graceful error handling for non-existing users or network issues.

## Prerequisites 📢
- Python 3.10+

## Installation & Setup 💻
1. Clone the repository.
```bash
git clone https://github.com/iiItzSpace/chesscom-user-stats.git
cd chesscom-user-stats
```
2. Run main.py:
```bash
python main.py
```
